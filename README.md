# TilerTalker

A simple tap-to-speak picture board (AAC). Tap a tile and the device says the phrase out loud.

**Open it:** https://tcdeveloper27.github.io/TilerTalker/

On an Android tablet, open the link in Chrome, then use **⋮ → Add to Home screen** so it opens full-screen like an app.

Everything is in `index.html`. It has no recordings and needs nothing else; phrases use the device's built-in voice.
